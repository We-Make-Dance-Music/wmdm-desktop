WMDM Desktop App — Distribution Targets
Software repositories, app directories, and discovery channels
═══════════════════════════════════════════════════════════════════════

Goal: Get the app listed in places where people search for software so
they discover WMDM organically and come back. Long-tail SEO + passive
traffic, not press releases.

───────────────────────────────────────────────────────────────────────
# CROSS-PLATFORM SOFTWARE DIRECTORIES (free listings)
───────────────────────────────────────────────────────────────────────

AlternativeTo                  https://alternativeto.net
  Why: People search "Splice alternative" — list as alt to Splice + Loopcloud
  Effort: 30 min, free, big SEO impact

Product Hunt                   https://www.producthunt.com
  Why: Permanent listing, ~2k visitors/day from category browsing
  Effort: Schedule launch day, prepare assets

Slant                          https://www.slant.co
  Why: Comparison/recommendation site, ranks well on Google
  Effort: 30 min, free

StackShare                     https://stackshare.io
  Why: Tech stack discovery, dev audience
  Effort: 30 min, free

G2                             https://www.g2.com
  Why: Software review aggregator, B2B-leaning but accepts consumer apps
  Effort: 1 hour for full profile

Capterra                       https://www.capterra.com
  Why: Owned by Gartner, enterprise software directory
  Effort: 1 hour

GetApp                         https://www.getapp.com
  Why: Same parent as Capterra, separate listing
  Effort: 30 min

SourceForge                    https://sourceforge.net
  Why: Old but still indexed by Google for "free software" searches
  Effort: 1 hour, free

───────────────────────────────────────────────────────────────────────
# MAC-SPECIFIC DIRECTORIES
───────────────────────────────────────────────────────────────────────

MacUpdate                      https://www.macupdate.com
  Why: Largest Mac software directory, $$ for premium
  Submit: https://www.macupdate.com/info/submit-app
  Effort: 1 hour

Mac App Store                  https://developer.apple.com/app-store
  Why: Maximum trust, but requires Apple Dev account ($99/yr)
  Effort: Significant (sandboxing, review process)
  Note: Tauri apps CAN ship to Mac App Store with effort

Setapp                         https://setapp.com
  Why: Curated Mac app subscription, revenue share
  Submit: https://setapp.com/apply
  Effort: Application + revenue sharing model

Homebrew Cask                  https://github.com/Homebrew/homebrew-cask
  Why: Power users install via `brew install --cask wmdm`
  Submit: PR to homebrew-cask repo with cask file
  Effort: 2 hours, free, very dev-friendly

───────────────────────────────────────────────────────────────────────
# WINDOWS-SPECIFIC DIRECTORIES
───────────────────────────────────────────────────────────────────────

Microsoft Store                https://partner.microsoft.com/dashboard
  Why: Built into Windows 10/11, trust + auto-update
  Effort: Significant (MSIX packaging)

WinGet                         https://github.com/microsoft/winget-pkgs
  Why: Microsoft's official package manager, `winget install wmdm`
  Submit: PR to winget-pkgs repo
  Effort: 2 hours, free

Chocolatey                     https://community.chocolatey.org
  Why: Most popular Windows package manager for power users
  Submit: nuspec package + PR
  Effort: 3 hours, free

Scoop                          https://github.com/ScoopInstaller/Main
  Why: Lightweight Windows package manager
  Submit: PR to bucket
  Effort: 1 hour, free

Ninite                         https://ninite.com
  Why: One-click installer for popular Windows apps
  Submit: contact form
  Effort: 30 min, hard to get accepted

# ESSENTIAL ASSETS TO PREPARE FIRST
───────────────────────────────────────────────────────────────────────

Before submitting anywhere, have these ready:

  □ App icon (512x512 PNG, transparent)
  □ App icon (1024x1024 PNG)
  □ 3-5 screenshots (1920x1080)
  □ App preview video (30-60 seconds)
  □ Short description (160 chars)
  □ Long description (500 words)
  □ Feature bullet list (5-10 items)
  □ Press kit folder (logos, screenshots, brand colors)
  □ Direct download URLs (Mac ARM, Mac Intel, Windows)
  □ Version history / changelog
  □ Privacy policy URL
  □ Terms of service URL
  □ Support / contact email
  □ Tags/categories
